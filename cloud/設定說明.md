# 碧潭能源管理系統：資料搬到 Google

網頁放在 GitHub Pages，資料存在你自己的 Google 試算表，照片存在 Google 雲端硬碟，Apps Script 當後端。
不需要開電腦，也不會像 Render 免費版那樣睡著、開啟時要等一分鐘，照片也不會因為重新部署而消失。

## 第一次設定（約 5 分鐘）

1. 開 <https://sheets.new> 建立新試算表，命名「碧潭能源 雲端資料」。
2. 選單「擴充功能 → Apps Script」，刪掉原本的內容，把 `cloud/Code.gs` 整份貼上。
3. 左側「專案設定（齒輪）」勾選「在編輯器中顯示 appsscript.json」，回編輯器打開 `appsscript.json`，換成 `cloud/appsscript.json` 的內容，按儲存（💾）。
4. 右上「部署 → 新增部署作業」，齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，第一次會要求授權：選你的帳號 →
     若出現「Google 尚未驗證這個應用程式」→「進階」→「前往（不安全）」→「允許」。
5. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

## 搬資料、切換

6. 把舊資料搬過去（只讀 MongoDB，雲端還沒有帳號時才接受；連線字串在 Render 的環境變數 `MongoDb__ConnectionString`）：

   ```
   set BITAN_MONGO_URI=mongodb+srv://...
   python cloud\migrate_from_mongo.py <網址>
   ```

   帳號密碼原封不動搬過去，大家用原本的密碼登入即可。舊照片的檔案已不在 Render 上，不會搬。
7. 把網址填進 `index.html` 的 `const CLOUD_URL = "";`，推送到 GitHub（GitHub Pages 會自動更新）。
8. 電腦版：把 `desktop/main.py` 的 `SITE_URL` 改成 `https://wu8858009.github.io/bitan-energy-pro-live/`，重新執行 `python build.py`。
9. 手機用新網址重新「加入主畫面」。

## 之後更新後端程式碼

Apps Script 貼上新版 `Code.gs` → 儲存 →「部署 → 管理部署作業 → ✏ 編輯 → 版本：新版本 → 部署」。網址不會變。

## 資料存放方式

| 工作表 | 內容 |
|---|---|
| Users | 帳號（密碼只存雜湊） |
| Stores / Sites | 門市、站點 |
| Readings / Daily | 每月讀數（含照片對應的雲端檔案 Id）、每日讀數 |
| AuditLogs | 操作日誌（保留最新 1000 筆） |
| Settings | 單價、瓦斯預算、管理費（各裝置共用） |

每格開頭的 `~` 是為了不讓試算表把內容自動轉成數字或日期，**請不要手動修改這些工作表**。
照片在雲端硬碟的「碧潭能源 照片」資料夾，維持私人。「誰在線上」放在 Apps Script 快取，不寫進試算表。

## 限制

- 每次存檔約 1～3 秒；登入約需幾秒（要驗證密碼）。
- 雲端版上傳前會把照片縮到長邊 1600 像素，佔用你 Google 帳號的雲端硬碟空間（免費 15 GB）。
- 在線狀態每 60 秒更新一次（原本 5 秒）。
- 多裝置同步：Apps Script 無法主動推送，畫面開著的裝置每 4 秒查一次有沒有變更，所以別台的改動約 5～10 秒內出現。畫面在背景時不查，切回來馬上查。
- 同時最多約 30 個請求，十幾個人同時使用沒問題。
